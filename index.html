Groovebox 100 Accord : – Touche ▶ ou un pad pour activer le son
Scène

Partition portée de percussion

En haut, hampes vers le haut : les mains (charleston, ride, crash, caisse claire, toms). En bas, hampes vers le bas : les pieds (grosse caisse, charleston au pied). Têtes en croix = cymbales ; « o » = charleston ouvert ; croix cerclée = cercle (cross-stick) ; triangle = cloche.

Comprendre le séquenceur

Chaque ligne est un instrument. Avec le débit doubles croches (1/16), chaque case est une double croche : 16 cases = une mesure à 4 temps, comptée 1 ti ke ta, 2 ti ke ta…. Avec le débit croches (1/8), 8 cases comptées 1 et 2 et… : plus simple pour commencer. Touche une case une fois pour une note, deux fois pour une note accentuée, trois fois pour une note fantôme (très légère, entre parenthèses sur la partition), quatre fois pour l'effacer.

Le swing retarde les notes entre les temps : à 100 %, des croches binaires deviennent ternaires (shuffle, jazz). Il s'applique à tous les instruments de la Groovebox.

Comprendre

Grille : jusqu'à 16 mesures, un accord par mesure. Touche ✎ Écrire, choisis une case puis un pad : l'accord s'inscrit et on passe à la case suivante. En lecture, la grille tourne en boucle, et la basse la suit.

Live : la grille est ignorée, l'accord joué est celui du dernier pad touché, au rythme choisi. Idéal pour improviser une grille en direct.

3, 4 ou 5 sons : le réglage vaut pour les prochains accords que tu inscris ; chaque case de la grille garde le sien, on peut donc mélanger triades, septièmes et neuvièmes.

Basse : choisis n'importe quelle note dans le menu pour la mettre sous les accords (F/G, C/E, C/B♭…). Si c'est une note de l'accord, c'est un renversement ; sinon, c'est une basse étrangère. La basse de la Groovebox joue alors cette note. Reviens sur « Fondamentale » pour les accords normaux.

Dominantes secondaires : un accord de 7e placé juste avant un accord de la tonalité pour le préparer, comme G7 prépare C (en C : A7 → Dm, E7 → Am…). Diminuée : l'accord de 7e diminuée un demi-ton sous l'accord visé (C♯dim7 → Dm). Substitution tritonique : l'accord de 7e un triton plus loin, la basse descend par demi-ton (E♭7 → Dm, D♭7 → C).

Échange intermodal : la deuxième rangée prend les accords d'un autre mode sur la même tonique (en C : Fm, A♭, B♭ empruntés à Do mineur…). Les pads « = » sont identiques à la tonalité.

Partition

Son de la basse

Comprendre

Le piano roll : les hauteurs de bas en haut, le temps de gauche à droite (16 doubles croches = une mesure). La basse est monophonique : une seule note à la fois.

Suivre les accords : la ligne est écrite sur un accord de Do (Do = fondamentale, Mi = tierce, Sol = quinte, en couleur). Pendant la lecture, elle est transposée sur chaque accord de la grille, et les tierces et quintes s'adaptent (majeur, mineur, diminué). Une seule ligne suffit donc pour tout le morceau.

La partition montre exactement ce que joue la basse, en clé de Fa : une case = une double croche, une note liée aux cases suivantes devient une croche, une noire… Les cases vides deviennent des silences (demi-soupir, soupir…).

Notes longues : choisis la durée (double croche, croche, noire, blanche, ronde) avant de toucher le piano roll, ou glisse le doigt vers la droite pour allonger la note. Une note longue, ce sont des cases liées à la suite.

Accent : la note est plus forte et le filtre s'ouvre plus. Liaison : la note s'enchaîne à la précédente sans être rejouée ; si c'est la même hauteur, elle est tenue ; sinon, le son glisse d'une note à l'autre (glissando).

Molette de pitch
Comprendre

Filtre : passe-bas = garde les graves (le son s'assombrit), passe-haut = garde les aigus (le son s'amincit), passe-bande = ne garde qu'une zone. La courbe montre ce que le filtre laisse passer, et elle bouge avec l'enveloppe du filtre pendant que tu joues.

ADSR : A = attaque, D = déclin, S = maintien (un niveau, pas un temps), R = relâchement. Le point blanc parcourt la courbe pendant que tu joues.

Molette de pitch : comme sur un vrai synthé, elle fait glisser la hauteur de toutes les notes vers le haut ou le bas, puis revient au centre quand on la lâche. Idéal pour imiter un bend de guitare.

Le synthé pour jouer une mélodie ou un solo par-dessus le groove. Ses réglages sont ceux du mini-synthé pédagogique (oscillateur, filtre, enveloppes). Ses effets se règlent dans l'onglet Mixeur.

Clavier MIDI

Comprendre

Branche ton clavier en USB puis touche Activer le clavier MIDI (Chrome ou Edge sur ordinateur, Chrome sur Android ; ça ne marche pas sur iPad et iPhone, Apple ne le permet pas).

  • Touches : elles jouent l'instrument choisi. Synthé : comme le clavier à l'écran, avec la vélocité. Basse : la basse en direct. Accords : les touches blanches déclenchent les accords de la tonalité (Do = I, Ré = II…), avec la basse et les sons choisis dans l'onglet Accords. Batterie : les notes de la norme General MIDI (Do = grosse caisse, Ré = caisse claire, Fa♯ = charleston…).
  • Pads du clavier (canal 10) : toujours la batterie.
  • Molette de pitch : la molette du synthé. Molette de modulation : le vibrato du synthé. Pédale de sustain : tient les notes du synthé. Volume (CC7) : le volume général.
  • Apprendre un bouton : touche ce bouton, puis un curseur de la Groovebox (n'importe lequel, dans n'importe quel onglet), puis tourne un bouton ou un fader de ton clavier : ils sont reliés.

Effets en insert :

Comprendre

Mute coupe un instrument, Solo n'écoute que lui (on peut en mettre plusieurs en solo). Le niveau règle son volume dans le mélange.

Les effets sont en insert : tout le son de l'instrument les traverse, dans l'ordre saturation → phaser → flanger → chorus → trémolo → delay. La réverb, elle, est en envoi : on envoie une partie du son de chaque instrument dans une seule réverb commune, comme dans un studio.
